# P1 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working Go MCP server that authenticates with imported cookies and serves `server_info`, `notebook_list` and `notebook_open` over the NotebookLM web RPC, with the codec, session, transport, cache and resolver every later plan builds on.

**Architecture:** Layered: `wire` (pure codec) → `session` (tokens, cookies) → `transport/rpc` (HTTP) behind `transport.Transport` → `nlm` (typed domain client) → `mcpserver` (tools). Every layer is tested against an `httptest` fake upstream that replays fixtures.

**Tech Stack:** Go 1.27, go-sdk v1.8.0, `encoding/json/v2` + `jsontext`, `golang.org/x/sync/singleflight`, `golang.org/x/time/rate`, `github.com/zalando/go-keyring` v0.2.8.

**Spec:** [docs/plans/2026-10-14-architecture.md](2026-10-14-architecture.md) and [research/rpc-catalog.md](../../research/rpc-catalog.md).

## Global Constraints

- Module path `github.com/candidloom-hub/notebooklm-mcp-go`; binary `notebooklm-mcp`; Go `1.27`; `CGO_ENABLED=0` builds must pass.
- Allowed dependencies in P1: `github.com/modelcontextprotocol/go-sdk@v1.8.0`, `golang.org/x/sync`, `golang.org/x/time`, `github.com/zalando/go-keyring@v0.2.8`. Any other dependency: stop and ask.
- Default host `notebook.google.com`; batchexecute path `/_/LabsTailwindUi/data/batchexecute`.
- Every function that does I/O takes `ctx context.Context` first and passes it on; never `context.Background()` below `main`.
- Never log cookie values, `at`, `SAPISID` or `f.req` bodies; use `safety.Redact`.
- Fixtures under `testdata/fixtures/<rpc-id>/<name>.json`; synthetic ones carry `"synthetic": true`.
- Tests run with `go test ./... -race`; no test touches the network except `-tags live`.

## Review Focus

1. Response chunk lengths that disagree with the payload (UTF-16 vs bytes, emoji and CJK titles) → decoder still returns the right frame. Test in Task 3.
2. HTTP 200 with position-5 status `[3]` or `[8]` → typed error, never success. Test in Task 3.
3. `GET /` redirected to `accounts.google.com` or `CookieMismatch` → `KindAuth` / `KindCookieBinding`, no retry loop. Test in Task 5.
4. Cookie jar with duplicate names across `.google.com` and the notebook host → `.google.com` wins, one header value per name. Test in Task 6.
5. Two concurrent `notebook_list` calls while the cache is cold → exactly one upstream request. Test in Task 8.
