# NotebookLM MCP / CLI / client upstreams: discovery

Date: 2026-10-14. Discovery only; nothing cloned, nothing run or installed.

## Conventions

- Stars, last push, archived flag, language, license: `gh api repos/{owner}/{repo}` and `.../license` on 2026-10-14 (source for every row: the repo URL in column 1).
- npm data: https://registry.npmjs.org/-/v1/search and `https://www.npmjs.com/package/<name>`. PyPI data: `https://pypi.org/pypi/<name>/json` (package list from `https://pypi.org/simple/`).
- "Access method" comes from the repo README, package.json or pyproject read via the GitHub contents API. "RPC" means the internal `batchexecute` endpoint of notebooklm.google.com. Where only a keyword scan of the README supports the label it is marked [unverified]; the analysis step must confirm it from code.
- "Latest version" is the package-registry version where a package exists, otherwise the latest GitHub release/tag, otherwise the manifest version.
- Product rename: the moodRobotics README states Google renamed NotebookLM to "Gemini Notebook" on 2026-07-16 (https://github.com/moodRobotics/notebooklm-mcp-server, referencing https://notebook.google/) [unverified against a Google source]. The GitHub descriptions of teng-lin/notebooklm-py and jacob-bd's repo were changed to "Gemini Notebook" and the PyPI project `gemini-notebook` exists (https://pypi.org/project/gemini-notebook/). Search for both names in later steps.

## Search queries used

GitHub repository search (`gh api search/repositories`, up to 10 pages x 100 each, 3,913 unique hits before filtering): `notebooklm mcp`, `notebooklm-mcp`, `notebooklm cli`, `notebooklm api`, `notebooklm`, `topic:notebooklm`, `topic:notebooklm-mcp`, `topic:notebooklm-api`, `topic:notebooklm-py`, `batchexecute notebooklm`, `notebook lm mcp`, `google notebooklm unofficial`, `notebooklm python`, `notebooklm typescript`, `notebooklm golang`, `notebooklm rust`, `notebooklm skill claude`, `notebooklm automation`, `notebooklm client`, `gemini notebook mcp`, `notebooklm enterprise api`, `notebooklm-mcp in:name`, `notebooklm in:name`, `notebooklm in:readme mcp`, `notebooklm obsidian`, `notebooklm browser extension`, `notebooklm podcast api`, `notebooklm in:description`.
Filtered to name/description/topics containing notebooklm or "gemini notebook": 3,309 repos; narrowed by MCP/CLI/API/SDK/client keywords to 393 candidates; 163 scanned (README, manifest, license, release).
Not run: `gh search code` (GitHub code search needs separate rate budget; repo-level keyword scan of README/manifests was used instead).

Package registries: npm registry search API for `notebooklm`, `notebooklm mcp`, `notebook-lm`, `nblm`, `gemini notebook` (706 unique packages, filtered to NotebookLM-related); PyPI simple index filtered by regex `notebook[-_.]?lm|nblm|gemini[-_.]?notebook|nlm` (39 names; fetched JSON for each). PyPI's own search page is behind a bot challenge and was not used.

MCP directories: official registry `https://registry.modelcontextprotocol.io/v0/servers?search=notebooklm` (3 distinct servers; also tried `notebook lm`, `gemini notebook`: zero hits); Smithery `https://registry.smithery.ai/servers?q=notebooklm` (1 NotebookLM server); Glama `https://glama.ai/mcp/servers?query=notebooklm` (web page; the API needs a key); PulseMCP `https://www.pulsemcp.com/servers?q=notebooklm` (web page; v0beta API is sunset); mcp.so `https://mcp.so/search?q=notebooklm`.
