# Best practices for our Go NotebookLM MCP server

Date: 2026-10-14. Synthesized from `research/notes/*.md` and `research/performance.md`. Each item: **practice**, why, evidence (note file, then upstream `file:line` as recorded in that note). Upstream codes as in [feature-matrix.md](feature-matrix.md#how-to-read-this). Items marked [proposal] are our design choice, not copied from an upstream. Nothing here was verified live.

Target stack (decided): Go, official `modelcontextprotocol/go-sdk` v1.8.0, stdio default; batchexecute RPC first, chromedp browser fallback only on transport/drift errors, optional Enterprise REST as a third transport; Apache-2.0; default host `notebook.google.com`.

## 1. Transport and codec

1. **One `Transport` interface with `Execute(ctx, req) -> raw`, `Session()`, `Refresh(ctx)`, `Close()`; builders and parsers never see the transport.** Lets RPC, in-page browser fetch and Enterprise REST share the tool layer, as CLAUDE.md requires. Evidence: [ICE](notes/icebear0828__notebooklm-client.md) `src/transport.ts:11-29`, `api.ts` takes an `RpcCaller`; [MIS](notes/missdeer__notebooklm-client.md) `internal/transport/transport.go:10-16` (behavior only, GPL).
2. **Session = `{at, bl, fsid, cookies (jar), host, authuser, userAgent, hl}` is the portable unit; only a browser can create it, HTTP can refresh it with `GET /`.** Evidence: ICE `src/types.ts:324-335`, `session-store.ts:164-301`; MIS `internal/session/refresh.go:1-110`.
3. **Package split: `batchexec` (wire, no I/O), `notebooklm` (typed operations), `auth`, `transport/{rpc,browser,enterprise}`, `mcp` (tools).** Pure codec is testable with fixtures. Evidence: [AGM](notes/agmmnn__notebooklm-sdk.md) `src/rpc/{encoder,decoder,core}.ts`; [DOK](notes/Dokkabei97__notebooklm-cli.md) `internal/rpc` -> `internal/api` -> `cmd`; [JUL](notes/julianoczkowski__notebooklm-mcp-2026.md) `protocol.py:1-12`.
4. **Decode frames structurally, not by declared length.** Strip `)]}'` (contiguous or char-per-line), escape raw control chars inside strings, extract top-level balanced arrays with a quote-aware scanner, fall back to a UTF-16-length splitter, fail if more than 10 percent of chunks are malformed. Lengths are UTF-16 code units and can be off by 2. Evidence: [TMC](notes/tmc__nlm.md) `wire.go:285-302`, `unescape.go:101-143`, `chunked.go:138-174`, `wrbfr.go:16-148`; [TL](notes/teng-lin__notebooklm-py.md) `rpc-reference.md:3297-3300`; [ERS](notes/ers123__notebooklm-mcp.md) commits `a3abf46`, `4e20855`; [SAH](notes/sahaand__mcp-notebooklm-go.md) `decoder.go:22-72`; performance.md s3.
5. **Lazy decoding with `encoding/json/v2` + `jsontext.Value`, stdlib only.** Measured: 33 allocs and ~310 us for a 37 KB envelope vs 9,385 allocs with `[]any`; third-party JSON libs gave no meaningful win. Evidence: performance.md s3 (measured on this machine).
6. **Typed decode results: payload / legitimate-null / refusal(status, details) / server error (`er`) / drift (id absent, other ids present) / login-or-antibot page (no frames).** Conflating them caused ROO's silent outages. Evidence: [ROO](notes/roomi-fields__notebooklm-mcp.md) `batchexecute.ts:56-127`; SAH `decoder.go:146-250`; [JB](notes/jacob-bd__gemini-notebook-mcp-cli.md) `base.py:841-848`; [DOK](notes/Dokkabei97__notebooklm-cli.md) `decoder_test.go:7-21` (bug pinned).
7. **Per-RPC null policy (`NullIsError`, `NullAllowed`, `NullAllowedUnlessRejected`) and "last non-null frame wins" for repeated ids.** Evidence: SAH `decoder.go:146-250`; AGM `allowNull`; [MFL](notes/MatrixForgeLabs__notebooklm-api.md) `rpc.rs:99-218`; TL `rpc-reference.md:3317-3328`.
8. **Read the in-band gRPC status at frame position 5 and the `google.rpc.Status` details; map 16 to auth, 8 or `UserDisplayableError` to quota, 3/5/9 per-RPC (9 is polysemic: sentinel errors).** Evidence: TMC `chunked.go:255-328`, `errors.go:10-340`, `notebooklm/errors.go`; TL `rpc-reference.md:3283, 3302-3315`; SAH `chat.go:461-482`.
9. **Stream-decode chat line by line; chunks are cumulative; select answer frames by the type flag, diff snapshots, keep the authoritative full text; stall timeout on parsed chunks, not socket reads; cap answer size and detect repeated blocks.** Evidence: TMC `client_chat.go:108-125, 546-552, 617-790`; TL `rpc-reference.md:998-1020`; [ARL](notes/arlinamid__notebooklm-mcp.md) `chat-rpc.ts:140-176`.
10. **Send the full request-options block per RPC from a data table with provenance (captured date, source), not scattered literals.** Magic constants (`627`, `"1"`, type lists) have unknown meaning and drift by cohort. Evidence: JB Avoid #7 (`constants.py:285-291`); [MOOD](notes/moodRobotics__notebooklm-mcp-server.md) `constants.ts:63-79`; SAH `rpc/encoder.go:50-60`.
11. **Accessor helpers that return `(value, ok)` plus a `DecodeShape{path, context}` error.** Positional arrays drift; errors must name the path. Evidence: MFL `error.rs`, `json_at`; DOK `decoder.go:175-224`; ARL `at(v, ...path)` `rpc-ops.ts:59-60`.
12. **Upload: register (`o4cbdc`) first, then resumable start and `upload, finalize`; stream the body; JSON metadata keys in fixed order; treat 5xx with `X-Goog-Upload-Status: final` as done.** Evidence: TMC `client_upload.go:495-731`; TL CHANGELOG Windows upload fix (`CHANGELOG.md:8-35`); JB `sources.py:866-967` (64 KiB chunks).
13. **Media downloads: separate cookie jar per domain, follow redirects manually re-sending Cookie, drop `OSID`/`__Secure-OSID`, cross-site `Sec-Fetch-*`, reject HTML bodies, retry CDN 404 shortly after generation.** Evidence: JB `download.py:177-205`, `base.py:559-590`; ROO `batchexecute.ts:260-291`, `tools/index.ts:3881`; AGM `artifacts.ts:795-825`; ICE commits `3b38f40`, `0181066`, `a2f7e10`; [LKA](notes/LocalKinAI__notebooklm-go.md) `auth.go:65-119`.

## 2. Auth lifecycle

14. **Acquire cookies by owning a dedicated browser profile (never the user's default profile) and reading cookies + `SNlM0e`/`FdrFJe`/`cfb2h` over CDP after a real sign-in.** Chrome 136+ ignores debugging flags on the default profile; owning a profile sidesteps DPAPI and App-Bound Encryption. Evidence: TMC `internal/auth/auth.go:550-612, 1027-1175`; [M4Y](notes/m4yk3ldev__notebooklm-mcp.md) `browser-auth.ts:204-370`; performance.md s6 (https://developer.chrome.com/blog/remote-debugging-port).
15. **Offer CDP attach to an already running Chrome and cookie import (pasted cURL/header/JSON, storage_state, cookies.txt) as alternatives.** Some users cannot or will not let us launch a browser; attach is indistinguishable from normal use. Evidence: LKA `login.go:140-265`; TMC `-cdp-url` (`auth.go:134-150`); [FAX](notes/Faxtom__notebooklm-mcp.md) `auth.py:949-1268`; [PAV](notes/PavelGuzenfeld__notebooklm-mcp.md) `auth_cli.py:96-163`; [WIN](notes/win4r__notebooklm-py.md) `import_browser_cookies.py:84-123`.
16. **Detect login completion by signed-in cookies plus a CSRF token on the app page, not by URL prefix; wait through the redirect chain before judging.** URL checks broke on the host rename in PP, PAN, TEN, M4Y. Evidence: [ERS](notes/ers123__notebooklm-mcp.md) `auth-manager.ts:45-70`; [PAO](notes/paolodalprato__notebooklm-mcp-structured.md) `browser-session.ts:160-200`; [PAN](notes/Pantheon-Security__notebooklm-mcp-secure.md) CHANGELOG FX-026; TL v0.8.5 `/login` probe.
17. **Validate a new session with a real read RPC (`wXbhsf`) before saving it; report DBSC-style rejection distinctly.** Evidence: MOOD `auth.ts:192-220`; [CW](notes/claude-world__notebooklm-skill.md) `auth_helper.py:41-120`.
18. **Recovery ladder, each rung once, single-flight across goroutines, with a cooldown:** L1 re-fetch `GET /` tokens; L2 reload jar from disk if another process refreshed it; L3 RotateCookies; L4 operator `NOTEBOOKLM_REFRESH_CMD` (argv, no shell, 60 s timeout); L5 headless re-mint on the dedicated profile (opt-out); else typed `AUTH_EXPIRED` with the exact login command. Evidence: TL ADR-0030 (`docs/adr/0030-one-recovery-ladder.md:151-156`); JB `base.py:1141-1190`; M4Y `auth-state.ts:354-380`; AGM `client.ts:72-81`; MIS `refreshguard.go`; FAX `auth.py:543-584` (cooldown).
19. **Never treat network/5xx during recovery as "auth expired"; never treat HTTP 400 as auth.** Evidence: JB `base.py:147-177`; ICE Avoid #2 (`client.ts:355-358`).
20. **Keepalive: RotateCookies at most every 10 minutes while active, rate-limited to 60 s per profile, using the jar minus host-scoped OSID cookies; merge `Set-Cookie` from every response; learn `f.sid` from `af.httprm`; persist atomically (temp + rename) with a file lock and a revision check.** Evidence: TL `keepalive.py:62-73`; MOOD `client.ts ~150-235`; M4Y `client.ts:62-72`, `transport.ts:121-131`; JB revision compare-and-save `base.py:1338-1370`; performance.md s7. Caveat: JB issue #316 says plain-HTTP RotateCookies refreshes only `SIDCC` (see rpc-catalog s6), so keep L5.
21. **Cookie storage: random 32-byte key in the OS keyring (`zalando/go-keyring`), cookie jar AES-GCM encrypted in a 0600 file under `os.UserConfigDir()` (Windows: owner-only ACL); env/file key fallback for headless Linux and Docker.** Windows Credential Manager caps secrets at 2,560 bytes, too small for a jar. Evidence: performance.md s7; JB `credential_store.py:1-33`; ERS `cookie-store.ts` (keychain-only, no fallback: Avoid); PAN `file-permissions.ts:57-230`; [KD](notes/K-dash__nblm-rs.md) `auth/oauth/mod.rs:260-343`.
22. **Windows App-Bound Encryption: do not decrypt Chromium cookie stores.** Chrome 127+ ABE needs Chrome itself; copying a profile fails ("token not found"). Supported Windows paths: dedicated profile, CDP attach, Firefox store or exported cookies.txt. Evidence: MIS README (behavior), [KAF](notes/KAFKA2306__nlm.md) `docs/auth-troubleshooting.md`; TMC `auth.go:663-710` stub `Local State`; [DOK](notes/Dokkabei97__notebooklm-cli.md) `chrome.go` macOS-only, drops `v20` silently.
23. **Plan for DBSC.** If Google binds session cookies to a device key, replay from Go stops working; the in-page fetch transport (browser supplies bound cookies) and Enterprise REST are the escape hatches. Detect it explicitly, do not loop. Evidence: performance.md s7 (https://developer.chrome.com/blog/dbsc-origin-trial); MOOD commit `eda535d`; PAO `browser-session.ts:165-190`; JB `cdp_transport.py:1-8`.
24. **Multi-account: one profile per account and per concurrent worker; `authuser` param and `x-goog-authuser` only for non-default accounts; hint "wrong account" on NOT_FOUND/PERMISSION_DENIED.** Concurrent users of one jar sign each other out. Evidence: TL `docs/auth-cookie-lifecycle.md`; TMC `authuser.go:5-12`; SAH `decoder.go:104`.
25. **Enterprise auth via `golang.org/x/oauth2/google` ADC (`TokenSource`), cache token until expiry, one refresh on 401; no shelling to gcloud per call.** Evidence: [ROB](notes/Robiton__notebooklm-mcp-cli.md) `enterprise_client.py:93-150`; KD `auth/mod.rs:123-166` (Avoid).

## 3. Drift resilience

26. **Overridable RPC ids and payload templates: built-in table, overridden by `rpc-overrides.json` in the config dir and by env, reloadable, consulted per call.** Ids rotate; an override ships a fix without a release. Evidence: TL `NOTEBOOKLM_RPC_OVERRIDES` (`encoder.py:28-33`); JB `base.py:97-116`; ROO `rpc-ids.ts:92-105`; ICE `rpc-config.ts:121-166`; MIS `internal/rpc/config.go:9-70`.
27. **Scrape `bl` from `cfb2h` at runtime; keep a dated fallback only for logging; never hard-code `f.sid`.** Evidence: TMC Avoid #1 (`rpc.go:292-299`); [JBc](notes/jacob-bd__notebooklm-cli.md) TECHNICAL_DEEP_DIVE s3; M4Y `auth.ts:62-65`; [PHO](notes/photon-hq__notebooklm-kit.md) `rpc-client.ts:53-54` (Avoid).
28. **Drift error type with the ids that were present, plus "login/anti-bot page" when no frames came back; drift trips the breaker toward the browser fallback.** Evidence: AGM `decoder.ts:184-196`; SAH `decoder.go:208-250`; JB `RPCDriftError`.
29. **Typed, lossless decode tests: each RPC request/response modelled as a Go struct (index = field-1 style tags or accessor table), decode a captured fixture, re-encode, diff; report unmodelled positions.** Evidence: TMC `internal/betool/betool.go:405-452`, `beprotojson.go:19-80`, `rpc_extensions.proto:9-93`. Adopt the verify idea, not TMC's 5k-line codegen (TMC Avoid #9).
30. **Sanitized HAR-derived fixtures with a record/replay RoundTripper (cookies and Authorization redacted); per-RPC `verified_at`, `host`, `source` metadata.** Evidence: TMC `internal/httprr/httprr.go`; SAH WIP.md ("audited offline, not live-verified"); [KIS](notes/Kisara-k__notebooklm-kit.md) probe-string capture (`XXPROBE_PROMPT_77QQ`).
31. **Nightly canary: a few read-only RPCs against a throwaway account; open an issue on failure; compare the live `bl` and id registry.** Evidence: DOK `.github/workflows/rpc-health.yml:1-50`; TL `scripts/check_rpc_health.py`.
32. **Do not ship a tool whose payload is not capture-verified; mark experimental or remove.** Evidence: M4Y commit `4b83e34` (5 tools removed after live audit); KAF AGENTS.md invariant; LKA "experimental" labels.
33. **Host abstraction in one function (`IsNotebookHost`), host learned at login and persisted per profile, probe the other host with its own cookie jar on bootstrap failure, and log which host and transport served each call.** ROO shipped a dead RPC path for 3 releases because the fallback hid it. Evidence: JB `utils/config.py:68-106`; ROO `tools/index.ts:4284-4308`, CHANGELOG 3.0.4; PAN `security.ts:30-52, 286-300`; KIS `bc32922`.
34. **Keep a protocol-quirks doc with discovery dates** (e.g. note title ignored on create, mind-map delete needs a timestamp step, autolabel DEADLINE_EXCEEDED is normal). Evidence: KD `docs/api/limitations.md`; JBc TECHNICAL_DEEP_DIVE; MIS `SYNC_BASELINE.md`.

## 4. Reliability

35. **Classify every RPC as read, idempotent write, or non-idempotent write. Retry reads and idempotent writes with exponential backoff (base 1 s, cap 30 s, 20 percent jitter, honor `Retry-After`, clamp to the call deadline); retry non-idempotent writes only on provably pre-send failures (connect error, pool timeout).** Replaying a sent POST duplicates notebooks, sources or chat turns. Evidence: TL `retry.py`, ADR-0005 (`docs/adr/0005-idempotency-taxonomy.md`), `_backoff.py:21-24`; JB `retry.py:36-41`; TMC Avoid #2 (`batchexecute.go:297-367`); KD Avoid #3; performance.md s4.
36. **Accepted-pending codes 3/9 on add-source and research import: list and reconcile by URL/Drive id before any retry; surface "unconfirmed" when the response is lost.** Evidence: JB `sources.py:431-470`, `research.py:380-405`; TL `docs/mcp-guide.md:607-640`, `rpc-reference.md:540-541`.
37. **Verify mutations by reading back** (rename, pin, share, delete, language, chat config). Turns silent no-ops into errors. Evidence: ARL `rpc-ops.ts:142-146, 215-218, 235-237, 247-249, 338-340, 407-409, 613-617`.
38. **Rate limits are mostly server quotas: do not retry quota (code 8, `UserDisplayableError`, daily limit) beyond one backoff; return a typed `QUOTA_EXHAUSTED` with reset time when `EylDcb` provides it.** Evidence: performance.md s4; TL `docs/quota-limits.md`, `_web/usage.py:59`; SAH `chat.go:461-482`.
39. **Client-side limits: global token bucket (start 3 req/s, burst 5) plus a stricter bucket for chat and generation; concurrency cap on fan-out (`errgroup.SetLimit` 3-4); per-notebook FIFO for chat.** go-sdk runs tool calls concurrently, so 5 parallel calls hit Google at once without this. Evidence: performance.md s1 and s4 [values are proposals]; ICE `client.ts:626-645`; ARL `utils/page-lock.ts:14-75`; TL chat queue concurrency 3.
40. **Singleflight for idempotent reads with a detached context per shared call; never coalesce mutations.** Evidence: performance.md s4; ICE `withRefreshGuard`.
41. **Long jobs: fire-and-return with an id, poll with backoff (TL 2 s to 10 s, timeout 300 s), shared poll loop per artifact; absence from a listing never proves deletion.** Evidence: TL `_artifacts.py:913-977`; [STR](notes/stratosphereips__strato-mcp-notebooklm.md) `client.py:663-780`; CW Avoid #5 (3600 s blocking waits).
42. **Timeouts: per-call context from the handler; 30 s normal RPC, 120-180 s chat total with stall detection, 300 s upload; no `Client.Timeout` on streaming.** Evidence: TL `_runtime/config.py:57-63`; TMC `client_chat.go:108-125`; DOK Avoid #3 (no timeout); performance.md s2.
43. **Mutations invalidate caches in the same handler (write-through); reads use TTL + stale-while-revalidate; `refresh: true` bypasses.** Evidence: performance.md s5; STR `resolver.py` (60 s TTL).

## 5. Fallback policy

44. **Fall back to the browser only on transport and drift classes:** connection failures, TLS/CookieMismatch-type rejections, drift (id absent), unparseable envelope, repeated 400 after a `bl` refresh. **Never** on 429/quota (same account, same quota), auth (16, 401/403 after the ladder), PERMISSION_DENIED (7), NOT_FOUND (5), or user errors (3 on bad input). Evidence: ROO Avoid #1 (fallback on any exception hid a dead primary and turned refusals into slow browser retries, `tools/index.ts:2057`, CHANGELOG 3.0.4); ARL `browser-session.ts:1365-1405` (no fallback on auth 16); performance.md "Contradictions" #1.
45. **Circuit breaker per (profile, transport): trips on drift/protocol errors, not on 429; half-open probe with `wXbhsf`.** Evidence: performance.md s4 (`sony/gobreaker/v2` option).
46. **Prefer in-page fetch over DOM automation as the first browser fallback:** the same RPC sent with `fetch` from inside the signed-in tab uses the browser's own (possibly device-bound) cookies and real TLS, and returns parseable frames; DOM clicking is the last resort for chat/add-source only. Evidence: ARL `rpc.ts:1-19`; JB `cdp_transport.py:1-8`, `base.py:910-969`; ICE `transport-browser.ts`. Note: in-page fetch does not help with payload drift; DOM does.
47. **Per-feature "no fallback" class; error text says so.** Evidence: ARL `browser-session.ts:1380-1384`; ROO "There is no DOM fallback on purpose" (`tools/index.ts:3393`).
48. **Report which transport served each call** in tool results (`transport` field) and `server_info`. Evidence: ROO lesson (CHANGELOG 3.0.4).

## 6. Browser automation (fallback and login)

49. **chromedp with the user's installed Chrome/Edge (or `chrome-headless-shell` in Docker); never download a browser; launch lazily on first fallback, keep warm for an idle window, then kill.** Evidence: performance.md s6 (chromedp v0.21.0 active; rod last release 2024); MOOD Avoid (postinstall Chromium download).
50. **Dedicated profile dir per account and engine, 0700, single owner guarded by a lock file; kill stale owners and clear `SingletonLock`/`DevToolsActivePort`; reset crash flags before launch.** Evidence: performance.md s6; M4Y `browser-auth.ts:142-180`; ICE `browser.ts:325-420`; [TEN](notes/tenyoru__notebooklm-mcp.md) profile conflicts doc.
51. **CDP on loopback only, ephemeral port discovered from stderr or `DevToolsActivePort`; never `--remote-allow-origins=*`, never a fixed 9222.** Evidence: M4Y `browser-auth.ts:11-14, 96-125`; ICE Avoid #7; JUL Avoid #1; [JAC](notes/jackc1111__antigravity-notebooklm-mcp.md) Avoid #3.
52. **Selector registry as data (embedded JSON overridable from disk): locale-independent classes > Material icon ligature text > ARIA roles > locale text; each control has alternatives, a "confirmed" date and a discovery script.** Evidence: [PP](notes/PleasePrompto__notebooklm-mcp.md) `selectors.ts:4-28, 406-408`; PAN `notebook-creation/selectors.ts:36-45`, `scripts/selector-discovery.ts`; ARL selector churn list.
53. **Chat completion detection: `.message-actions` appearing = done; strip `thinking-chain-view`; count answer bubbles instead of comparing text to old answers; stability poll only as secondary; placeholder filter.** `div.thinking-message` was removed by Google and broke PP v1, PAN, TEN. Evidence: PAO `selectors.ts:46-67`, `page-utils.ts:79-128, 353-401`; ARL chat.ts diff (bubble count); PP `chat.ts:28-104, 227-304`.
54. **Per-tab FIFO lock with queue position in progress messages and cancellation; idle reaper skips busy tabs.** Evidence: ARL `utils/page-lock.ts:14-75`, `session-manager.ts:248`; PP Avoid #2 (no lock); PAN Avoid #2 (claimed mutex absent).
55. **Dismiss promo dialogs by Angular host-tag allowlist; anchor modals on `[role="dialog"]`.** Evidence: ARL `dialogs.ts:1-40`; PP `selectors.ts:138-145`.
56. **One browser per Google account across processes (leader/follower or singleton backend).** Two Chromes on one session may get it revoked. Evidence: ARL `coordinator.ts:1-120`; PAO `singleton/*`.
57. **No stealth JS injection or fake fingerprints by default; no hard-coded timezone/locale/WebGL.** Inconsistencies are themselves signals and the arms race is ToS-adjacent. Evidence: ICE `browser.ts:109-131` (Avoid #6); PP Avoid #8; MIS `72dba99` (Avoid #2).
58. **Sandbox on; `--no-sandbox` only in containers that need it.** Evidence: PAO `shared-context-manager.ts:157-160`; [IVA](notes/ivanovich1071__notebooklm-mcp.md) Docker flags.
59. **Do not seed a fresh profile from exported cookies and assume it is signed in; validate.** Evidence: PAO `browser-session.ts:165-170`.

## 7. MCP tool design

60. **Task-shaped tools (~30), typed enums in the schema, discriminators only where annotations stay honest; fuzzy resolver on every notebook/source/artifact param (id, exact title, unique prefix, substring) with suggestions on ambiguity.** Evidence: STR README "Design Principles", `resolver.py`; TL `docs/mcp-guide.md:256-290`, ADR-0025 (38 tools too many); STR Avoid #1 (`options` as JSON string), Avoid #3 (mixed annotations).
61. **Error result shape `{status:"error", code, error, retriable, guidance, suggestions, transport}` returned as `IsError` tool results, not protocol errors; auth errors carry the exact recovery command.** Evidence: STR `errors.py:30-37`; TL error codes (`docs/mcp-guide.md`); CW `[AUTH_REQUIRED]` (`common.py:45-53`); TMC `IsError` text results; performance.md s1.
62. **Pass the handler `ctx` to every outbound call; never `context.Background()` in handlers.** Cancellation must abort the HTTP call and release limiter slots. Evidence: TMC Avoid #3 (`internal/nlmmcp/tools.go:203,228,252,272`); performance.md s1.
63. **Annotations on every tool (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`), decided per tool so one tool never mixes read and destructive actions.** Evidence: STR `_tool_annotations`; TMC `server.go:12-26`; PAN commit `125755c`.
64. **Destructive actions: preview unless `confirm=true`; use MCP elicitation when the client supports it.** Evidence: ARL `handlers.ts:73-79, 1172-1195`; TL `needs_confirmation`; CW `server.py:92-101`.
65. **Progress notifications for long jobs (generation, research, uploads, source wait, long chat), only when the client sent `progressToken`, at most 1 per second, with heartbeats about every 15 s so clients with progress-reset timeouts do not abort.** Evidence: TMC `research_watch.go` (tested with `NewInMemoryTransports`); PAO `page-utils.ts:262-273`; performance.md s1; [ASC](notes/asccclass__notebooklm-go.md) Avoid #4 (token = request id is a spec deviation).
66. **Fire-and-return plus status tools for anything slower than ~40 s; `wait` param with a cap below typical host timeouts (~60 s).** Evidence: ARL CHANGELOG 3.3.1 (90 s wait hit 60 s client timeouts); TL detached `chat_start`; CW Avoid #5.
67. **Composite reads to save round trips and tokens (`notebook_open`), progressive disclosure (`detail`, `include_references`), pagination envelope `{items,total,offset,limit,has_more,next_offset}`.** Evidence: STR `client.py:137-165`; TMC `tools.go:165-172`.
68. **Tool profiles/groups to shrink `tools/list` (minimal/standard/full + disabled list).** Evidence: JB `tool_groups.py:1-144`; PP `settings-manager.ts:30-54`; ASC `settings.go:12-150`; [WAN](notes/wangjing0__notebooklm-mcp.md) `settings_manager.py:11-60`.
69. **Server `instructions` carry recovery steps, supported kinds and safety rules; inject notebook titles briefly, not 120-line templates.** Evidence: CW `server.py:32-43`; PP `definitions.ts:18-32`; PAO Avoid #3.
70. **Declare only implemented capabilities; answer `prompts/list` if hosts call it.** Evidence: PAO `server-core.ts:88-118`.
71. **No stateful "current notebook" or "last answer" globals; every call carries ids.** Evidence: [KHE](notes/khengyun__notebooklm-mcp.md) Avoid #1-2 (`client_rpc.py:111-115, 194-209`).
72. **Return file paths or resource links for large outputs; do not duplicate large bodies into both structured and text content.** Evidence: performance.md s1 "Structured output"; STR Avoid #7.
73. **Tests: go-sdk in-memory transports for handlers, plus one process-level stdio smoke test (initialize, tools/list, tools/call) and a protocol-version `2026-07-28` negotiation test.** Evidence: TMC `research_watch_test.go:139`; KAF `cmd/nlm/mcp_test.go:11-170`; performance.md s1.

## 8. Security

74. **Untrusted output: NotebookLM answers contain user-source text. Strip zero-width/bidi characters, NFKC-normalize only for detection, flag injection patterns as `security_warnings`, never rewrite silently; no imperative suffixes ("EXTREMELY IMPORTANT...", follow-up reminders) on tool output.** Host injection guards flagged PP's reminder; PAN still ships it by default. Evidence: PAN `response-validator.ts:70-79, 227-330`, Avoid #1 (`config.ts:24-25, 184`); ERS `security/response-sanitizer.ts:1-60`; PP CHANGELOG 2.0.0.
75. **Log redaction at the sink: one `Redact()` for cookies, `at` tokens, SAPISIDHASH, `key=value` secrets, URL userinfo, emails, absolute paths; logs to stderr only; no response-body previews.** Evidence: PAN `security.ts:304-348` (applied at call sites: centralize instead); TMC `batchexecute.go:88-120`, commit `eb168c8`; ERS Avoid #3 (`rpc-client.ts:69-70`); LKA Avoid #6.
76. **Path validation: resolve symlinks, require paths inside allowed roots (MCP `roots/list` or configured roots), deny system dirs on all OSes including Windows, no overwrite unless asked, never relocate paths silently.** Evidence: PAN `security.ts:417-480` (POSIX-only denylist: Avoid #9); ARL `utils/file-roots.ts:1-30`; CW `common.py:573-626`; [STU](notes/studiogo__notebooklm-mcp.md) Avoid #4.
77. **SSRF guard on user-supplied source URLs: https/http only, scheme blocklist, reject private, loopback, link-local and metadata ranges after DNS resolution.** Google fetches the URL, but internal hostnames still leak intent and the browser fallback may fetch locally. Evidence: PAN `webhook-dispatcher.ts:146-168` (resolve + re-check) vs `security.ts:184-205` (no DNS: Avoid #10); ROB `services/sources.py:168-290, 410-422`.
78. **HTTP transport: loopback bind by default, refuse non-loopback without an explicit flag, validate `Origin`/`Host`, require a random bearer token; no wildcard CORS.** Evidence: performance.md s1; CW `server.py:272-278`; PAO `singleton/backend.ts:32-41`; ROO Avoid #6 (`0.0.0.0`, CORS `*`); PP Avoid #10; PAV Avoid #1.
79. **Secrets never in argv, temp files or env-derived child processes; no `curl` shell-outs with cookies.** Evidence: TMC Avoid #5 (`batchexecute.go:865-933`); ICE commit `f8b8151` (ARG_MAX/ps exposure).
80. **Never store Google passwords or TOTP secrets; no auto-login.** Evidence: PP Avoid #6; WAN Avoid #3; ASC Avoid #2; PHO Avoid #2.
81. **No self-update, no postinstall downloads.** Evidence: MOOD Avoid #1 (`src/update.ts`).
82. **Scope cookie reads: CDP `Network.getCookies` with explicit URLs (both hosts, accounts.google.com, googleusercontent), not `getAllCookies`.** Evidence: ROB `utils/cdp.py:1336-1363`; JUL Avoid #1; M4Y Avoid #2.
83. **Supply chain: Gitleaks and pinned actions in CI, SBOM and cosign-signed checksums at release, Windows in the CI matrix.** Evidence: KAF `.github/workflows/secret-scan-gitleaks.yml`, `actions-safety.yml`; MFL `ci.yml` (ubuntu + windows); performance.md s10.
84. **Keep scope tight: no compliance suites, webhooks, content pipelines or Gemini API side paths inside this server.** Evidence: PAN Avoid #7 (21-module compliance suite); CW Avoid #2.

## 9. Performance

85. **One process-wide `http.Client` per profile with a tuned Transport: `ForceAttemptHTTP2`, `MaxIdleConnsPerHost` 8, TLS session cache, no manual `Accept-Encoding`, `CheckRedirect` returning `ErrUseLastResponse`.** Evidence: performance.md s2. Anti-pattern: new client per call or per chat (JB `conversation.py:538`, `sources.py:915`; TMC `client_chat.go:477`; WAN `client.py:310`).
86. **Cache `at`/`bl`/`f.sid` across calls; refresh only on auth/drift signals or TTL. Never re-fetch the homepage per tool call.** Evidence: ROO Avoid #3 (`tools/index.ts:4312-4325`); MOOD single cached client; ERS 5-minute CSRF cache.
87. **Never launch a browser to obtain cookies for RPC calls; read the encrypted store.** Evidence: ROO Avoid #2 (`tools/index.ts:4278`); performance.md s6 ("Never launch at startup").
88. **Stream chat; do not buffer the whole response before parsing (megabytes of cumulative chunks).** Evidence: JB Avoid #3 (`conversation.py:549-693`); ARL Avoid #3; ROO; PHO (only true incremental reader, `streaming-client.ts:136-214`).
89. **Avoid redundant pre-calls: cache source ids and conversation id per notebook instead of `rLM1Ne` + `hPTbtc` before every ask; one cached source list per ask for citation titles.** Evidence: JB Avoid #4 (`conversation.py:403-442`); ARL perf note (3 round trips); STR Avoid #2 (`sources.get` per reference).
90. **Batch where the wire allows it: many URL specs in one `izAoDd`, `X1snv` async adds, `batchCreate`/`batchDelete` on Enterprise; skip N+1 freshness checks by default.** Evidence: TL `rpc-reference.md:3407-3413`; STR Avoid #4; JBc `--skip-freshness`.
91. **Lazy startup: register tools, nothing else; no keyring, network or browser before the first tool call.** Measured `initialize` ~17 ms p50, ~12 MB. Evidence: performance.md s8; KHE/STU lazy client (`server.py:68-87`).
92. **Do not spend effort on PGO, GOAMD64>v1, UPX or third-party JSON.** Evidence: performance.md "Contradictions" #10.
93. **Benchmarks B1-B10 with benchstat in CI; `httptrace` connection-reuse metric.** Evidence: performance.md s9.

## Anti-patterns seen upstream

1. Falling back to the browser on any exception, including quota and permission refusals; it hid a dead RPC path for three releases (ROO `tools/index.ts:2057`, CHANGELOG 3.0.4).
2. Launching a browser context just to read cookies for every RPC call (ROO `tools/index.ts:4278`).
3. Re-fetching the homepage and rebuilding the client on every tool call (ROO `tools/index.ts:4312-4325`).
4. New HTTP client per request, per chat or per upload step (JB `conversation.py:538`, `sources.py:915`; TMC `client_chat.go:477`; WAN `client.py:310`; ICE curl tier spawns a process per call).
5. Buffering the full chat stream then picking the longest text, sometimes without the answer/thinking flag (JB, ROO, ARL, ICE `parser.ts:284-312`, LKA, M4Y).
6. Treating a null result with a position-5 status as success (DOK `decoder_test.go:7-21`; MOOD `extractRpcResult`; MFL; LKA).
7. Returning the first `wrb.fr` frame regardless of id (JAC `api-client.ts:117-140`; WAN `client.py:152-165`).
8. Parsing by splitting lines and trusting or ignoring lengths naively (ROO `batchexecute.ts:156-158`; LKA `rpc.go:164-196`).
9. Retrying non-idempotent mutations, no jitter, no `Retry-After` (TMC `batchexecute.go:297-367`; KD; MFL).
10. Treating HTTP 400 as auth expiry (ICE `client.ts:355-358`) or keyword-matching error text to trigger cookie re-import (STU `server.py:107`; WIN `_AUTH_ERROR_SIGNALS`).
11. Hard-coded host, `bl`, `f.sid`, `_reqid` (MOOD `constants.ts:53,61`; PHO `rpc-client.ts:53-54`; DOK `encoder.go:172`; JUL; AGM cookie-domain allowlist excluding `notebook.google.com`).
